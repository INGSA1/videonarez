# Videonarez

Лёгкий видео-нарезчик клипов и хайлайтов для Windows 10/11 на **Rust + Tauri v2 + Svelte 5 + FFmpeg**.
Реализованы все 5 этапов архитектурного плана: редактор готовых файлов, фоновый захват экрана/окна игры
со звуком, буфер повтора в оперативной памяти с работой из трея, автоопределение игры, очередь экспорта и установщик.

## Этап 5

- **Авто: игра** — буфер сам включается, когда полноэкранная игра (fullscreen или borderless) держится
  на переднем плане, и выключается, когда её процесс завершён. Браузеры, плееры и оболочка Windows игнорируются,
  можно добавить свои исключения. Файлы называются по игре: `ZenlessZoneZero_2026-11-06_13-20-37.mp4`.
- **Очередь экспорта** — задания выполняются по одному в фоне; можно открыть следующий файл и добавить его, не дожидаясь.
- **Автозапуск с Windows** — сразу в трей (`--tray`): окно и WebView2 не создаются, процесс занимает ~5 МБ.
- **Безопасность захвата.** По умолчанию — Windows.Graphics.Capture (как Xbox Game Bar и OBS). Прямой захват AMD
  (`vsrc_amf`, zero-copy) — экспериментальная опция: при резкой остановке во время игры был замечен сбой драйвера.
  FFmpeg останавливается мягко (`q`, для AMF/DXGI ~150 мс), принудительно — только если не завершился сам.

Установщик NSIS: ~54 МБ (приложение 5 МБ + FFmpeg).

## Захват и буфер повтора

- **Захват на GPU.** Кодирование — аппаратное (AMF / NVENC / QuickSync). На NVIDIA/Intel кадры WGC идут в энкодер
  без копирования; на AMD по умолчанию WGC с копированием кадра (~1,5% CPU), а zero-copy `vsrc_amf` включается
  опцией. Если способ не запустился, автоматически пробуется следующий, вплоть до DXGI Desktop Duplication.
- **Буфер повтора в ОЗУ.** FFmpeg отдаёт MPEG-TS в процесс Rust, поток режется на куски по ключевым кадрам (раз в секунду),
  старые куски выбрасываются. На диск ничего не пишется до нажатия **Alt+F10** — тогда последние N секунд за ~0,2 с
  сохраняются в MP4 без перекодирования.
- **Запись** (**Alt+F9**) пишет тот же поток в файл, начиная с текущего ключевого кадра.
- **Звук через WASAPI:** весь системный звук или *только звук окна игры* (Process Loopback — без Discord и музыки),
  микрофон — отдельной дорожкой. Видео и звук привязаны к одной шкале реального времени (без дрейфа).
- **Источник:** монитор или конкретное окно (запоминается по exe).
- **Трей:** закрытие окна полностью выгружает WebView2 (−250 МБ), захват продолжается; повторный запуск или клик по значку
  возвращает окно. Глобальные горячие клавиши работают и в игре.

Замеры на RX 7600, 1080p60, 20 Мбит/с: FFmpeg ~1,5% CPU и ~60 МБ, ядро Rust ~15–20 МБ + буфер (≈100 МБ на 60 с),
задержка буфера ~0,1 с, рассинхрон звука ±40 мс.

## Что умеет

- **Открытие любых видео** (MP4, MKV, MOV, WebM, AVI…) через кнопку, Drag-and-Drop или «Открыть с помощью».
  Файл не читается в память: плеер получает его кусками по 4 МБ через протокол `clip://` с HTTP Range (206).
- **Предпросмотр с аппаратным декодированием** WebView2. Если формат не играет напрямую — автоматически
  делается ремукс-прокси (секунды) или облегчённый 720p-прокси на GPU. Экспорт всегда идёт из оригинала.
- **Таймлайн на canvas**: миниатюры только по ключевым кадрам, звуковая волна, масштаб колесом, ручки In/Out.
- **Авто-маркеры хайлайтов** по пикам громкости (выстрелы, крики, взрывы) и кнопка «Клипы из пиков».
- **Три режима нарезки**:
  1. *Мгновенно* — `-c copy`, ~0 нагрузки, без потери качества (режет по ключевым кадрам);
  2. *Точно* — Smart Cut: перекодируется только участок до первого ключевого кадра, остальное копируется;
  3. *Сжать / изменить* — GPU (NVENC / AMF / QuickSync) или CPU: разрешение, FPS, кадрирование 9:16 / 1:1 / 4:5…,
     качество, битрейт или **точный размер файла** (Discord 10 МБ и т.п.), сведение нескольких аудиодорожек с громкостью.
- **Список клипов**, пакетный экспорт или склейка в один хайлайт.
- **Пресеты**: Discord 10/50 МБ, Telegram, Shorts/TikTok/Reels (1080×1920), YouTube, HEVC.
- **Минимальная нагрузка**: все процессы FFmpeg с приоритетом *ниже среднего* (настраивается до *минимального*),
  без консольных окон; лимит потоков CPU; анализ предыдущего файла отменяется при открытии нового.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` / `K` | пуск / пауза |
| `←` `→` | кадр назад / вперёд |
| `Shift`+`←` `→` | ±1 с |
| `J` / `L` | ±5 с |
| `I` / `O` | начало / конец клипа |
| `Enter` | добавить клип в список |
| `P` | проиграть выделенное |
| `Del` / `Esc` | удалить / снять выбор клипа |
| `+` `−` `0` | масштаб таймлайна |
| `Ctrl+O` / `Ctrl+E` | открыть / экспорт |

## Сборка

Нужны Rust (MSVC), Node.js и FFmpeg (sidecar):

```powershell
winget install Gyan.FFmpeg.Essentials
# скопировать бинарники как sidecar (имена с target triple обязательны):
copy <ffmpeg>\bin\ffmpeg.exe  src-tauri\binaries\ffmpeg-x86_64-pc-windows-msvc.exe
copy <ffmpeg>\bin\ffprobe.exe src-tauri\binaries\ffprobe-x86_64-pc-windows-msvc.exe

npm install
npm run tauri dev      # разработка
npm run tauri build    # установщик NSIS в src-tauri\target\release\bundle\nsis
```

## Автообновление

Приложение раз в 6 часов (и при открытии окна) проверяет
`https://84-201-181-80.sslip.io/videonarez/latest.json`. Если вышла новая версия, сверху появляется
полоса «Обновить и перезапустить»; установщик скачивается, его подпись проверяется публичным ключом
из `tauri.conf.json`, затем он ставится в тихом режиме и приложение перезапускается.

Выпуск новой версии — одна команда:

```powershell
.\scripts\release.ps1 -Version 0.2.1 -Notes "Что изменилось"
```

Скрипт проставит версию, соберёт и подпишет установщик, загрузит его и `latest.json` на сервер
(в `/var/www/videonarez-updates`, раздаёт Caddy) и проверит результат по HTTPS.

**Ключ подписи** — `%USERPROFILE%\.tauri\videonarez-updater.key`. Сделайте резервную копию: без него
следующее обновление подписать нельзя, а установленные копии принимают только эту подпись.
В репозиторий ключ не попадает.

## Структура

```
src/                         Svelte 5 фронтенд
  components/VideoPlayer     плеер clip://, покадровый шаг, рамка кадрирования
  components/Timeline        canvas: линейка, миниатюры, волна, пики, клипы, In/Out
  components/ExportPanel     режимы, пресеты, кодек/GPU, размер, звук
  components/SettingsModal   приоритет, потоки, кодировщики, кэш
  lib/store.svelte.ts        состояние и вызовы IPC
src-tauri/src/
  main.rs                    точка входа, протокол clip://, команды
  ffmpeg.rs                  поиск sidecar, запуск с приоритетом, прогресс
  editor/stream_server.rs    HTTP Range (206) без загрузки файла в память
  editor/probe.rs            метаданные ffprobe
  editor/trimmer.rs          Copy / Smart Cut / GPU-экспорт, склейка, целевой размер
  editor/thumbnails.rs       миниатюры по I-кадрам
  editor/waveform.rs         волна (моно 8 кГц потоком) и детектор пиков
  editor/proxy.rs            прокси для предпросмотра
  config/gpu.rs              автоопределение NVENC/AMF/QSV пробным кодированием
  config/settings.rs         настройки JSON
  capture/sources.rs         мониторы (DXGI), окна, видеокарта
  capture/audio.rs           WASAPI: системный звук, Process Loopback, микрофон
  capture/pipeline.rs        командная строка FFmpeg и «лестница» способов захвата
  capture/ring.rs            кольцевой буфер MPEG-TS по ключевым кадрам
  capture/recorder.rs        запуск/остановка, сохранение повтора, запись, автоперезапуск
  capture/games.rs           автоопределение полноэкранной игры
  editor/queue.rs            пакетная очередь экспорта
  shell.rs                   трей, глобальные горячие клавиши, пересоздание окна
```
