# Videonarez

Программа для Windows, которая держит последнюю минуту игры в памяти и по нажатию клавиши
превращает её в клип. Встроенный редактор обрезает клип, сжимает его под Discord или
переводит в вертикальный формат для Shorts.

Всё работает локально и почти не нагружает компьютер: видео кодирует видеокарта, а на диск
ничего не пишется, пока вы сами не сохраните момент.

## Скачать

Установщик лежит в [последнем релизе](https://github.com/INGSA1/videonarez/releases/latest).
Нужна Windows 10 (версия 2004 или новее) или Windows 11, 64-битная. FFmpeg уже внутри,
ничего дополнительно ставить не нужно.

Обновления приходят сами: программа проверяет их при запуске и раз в несколько часов
и предлагает установить новую версию в один клик.

## Как пользоваться

1. Откройте вкладку «Захват» и нажмите «Ждать игру». Когда запустится полноэкранная игра,
   буфер включится сам.
2. Случилось что-то интересное — нажмите `Alt+F10`. Последние 60 секунд сохранятся в
   `Видео\Videonarez` меньше чем за секунду.
3. Нажмите на клип в галерее, отметьте начало и конец клавишами `I` и `O`
   и экспортируйте: как есть, точно до кадра или под нужный размер.

## Захват

- **Буфер повтора.** Последние 15 секунд – 5 минут хранятся в оперативной памяти.
  Минута в 1080p при 20 Мбит/с занимает около 100 МБ.
- **Запись** по `Alt+F9`, начинается с момента нажатия.
- **Что записывать:** любую полноэкранную игру (программа находит её сама), конкретный монитор
  или конкретное окно.
- **Звук отдельными дорожками.** Звук игры или всей системы, отдельные дорожки для выбранных
  приложений (Discord, браузер, музыка) и микрофон. В режиме игры можно писать звук только из неё,
  без голосового чата и музыки.
- **Работа из трея.** Если закрыть окно, захват продолжится, а интерфейс выгрузится из памяти.
  Можно запускать вместе с Windows сразу в трей.
- **Горячие клавиши** работают и внутри игры, их можно переназначить.

Нагрузка на RX 7600 при 1080p, 60 кадров в секунду: около 1,5–1,7% процессора и 60 МБ памяти
на кодирование, плюс сам буфер. Последний кадр клипа отстаёт от нажатия клавиши примерно на 0,1 секунды,
звук расходится с картинкой не больше чем на 40 мс.

## Редактор

- Открывает MP4, MKV, MOV, WebM, AVI и другие форматы, в том числе многочасовые записи:
  файл не загружается в память целиком.
- Шкала с кадрами, волной звука и метками громких моментов. Из меток можно сделать клипы
  одной кнопкой.
- Три способа нарезки:
  - **мгновенно** — без перекодирования и потери качества, режет по ключевым кадрам;
  - **точно** — до кадра, перекодируется только кусочек в начале;
  - **перекодировать** — на видеокарте, с выбором разрешения, частоты кадров, кадрирования и размера файла.
- Готовые настройки: Discord до 10 и до 50 МБ, Telegram, Shorts/TikTok/Reels 9:16, YouTube.
- Звуковые дорожки: у каждой своя волна, выключатель и громкость до 200%. При просмотре слышны
  все сразу, при экспорте их можно свести в одну или оставить раздельными.
- Несколько клипов из одного файла можно выгрузить отдельными файлами или склеить в один.
- Очередь экспорта: пока выгружается один файл, можно размечать следующий.

## Горячие клавиши

Везде, включая игры:

| Клавиша | Действие |
|---|---|
| `Alt+F10` | сохранить повтор |
| `Alt+F9` | начать или остановить запись |

В редакторе:

| Клавиша | Действие |
|---|---|
| `Пробел`, `K` | пуск и пауза |
| `←` `→` | на кадр назад и вперёд |
| `Shift` + `←` `→` | на секунду |
| `J`, `L` | на 5 секунд |
| `I`, `O` | начало и конец клипа |
| `Enter` | добавить клип в список |
| `P` | проиграть выделенное |
| `Del`, `Esc` | удалить клип, снять выбор |
| `+`, `−`, `0` | масштаб шкалы |
| `Ctrl+O`, `Ctrl+E` | открыть видео, экспорт |

## Где что хранится

| Что | Где |
|---|---|
| Клипы и записи | `Видео\Videonarez` (меняется в настройках) |
| Настройки | `%APPDATA%\com.videonarez.app\settings.json` |
| Превью клипов, копии для просмотра, дорожки | `%LOCALAPPDATA%\com.videonarez.app\` (кэш; копии для просмотра очищаются в настройках и удаляются сами через 3 дня) |

Программа ничего не отправляет в интернет. Единственный сетевой запрос — проверка обновлений:
она скачивает небольшой файл с номером последней версии.

## Ограничения

- Проверено на видеокартах AMD. Для NVIDIA (NVENC) и Intel (QuickSync) пути захвата есть,
  но на этих картах ещё не запускались. Без поддерживаемой видеокарты кодирует процессор.
- «Прямой захват AMD» в настройках экспериментальный: с ним во время игры был замечен сбой
  видеодрайвера. По умолчанию используется стандартный захват Windows, как в Xbox Game Bar и OBS.
- Окно, в котором ничего не меняется, Windows отдаёт редкими кадрами, поэтому запись такого окна
  получается с переменной частотой кадров. На игры это не влияет.
- Только Windows.

## Сборка из исходников

Понадобятся Rust (MSVC), Node.js и FFmpeg. FFmpeg кладётся рядом с приложением как sidecar,
имена файлов с target triple обязательны:

```powershell
winget install Gyan.FFmpeg.Essentials
copy <путь к ffmpeg>\bin\ffmpeg.exe  src-tauri\binaries\ffmpeg-x86_64-pc-windows-msvc.exe
copy <путь к ffmpeg>\bin\ffprobe.exe src-tauri\binaries\ffprobe-x86_64-pc-windows-msvc.exe

npm install
npm run tauri dev     # запуск для разработки
npm run tauri build   # установщик в src-tauri\target\release\bundle\nsis
```

Как выпускаются версии и устроены обновления — в [docs/RELEASING.md](docs/RELEASING.md).

## Как устроено

Интерфейс на Svelte 5 внутри Tauri 2 (WebView2), вся работа с видео и звуком на Rust.
Сами видео обрабатывает FFmpeg, который запускается отдельными процессами с пониженным
приоритетом.

- **Захват.** FFmpeg захватывает экран через Windows.Graphics.Capture и кодирует его видеокартой.
  В программу на Rust он отдаёт поток MPEG-TS, который режется на куски по ключевым кадрам
  (раз в секунду) и хранится в памяти. Сохранение повтора просто склеивает последние куски в MP4
  без перекодирования.
- **Звук** захватывается через WASAPI, в том числе звук отдельных процессов (Process Loopback).
  Видео и звук привязаны к одним часам, поэтому не расходятся со временем.
- **Просмотр в редакторе.** Видео отдаётся плееру кусками по 4 МБ через собственный протокол
  с поддержкой HTTP Range, поэтому даже большой файл открывается сразу.

```
src/                        интерфейс (Svelte 5)
  components/               плеер, шкала, экспорт, захват, галерея, очередь, настройки
  lib/                      состояние, микшер дорожек, форматирование, пресеты
src-tauri/src/
  main.rs                   запуск, трей, протокол clip://, команды
  ffmpeg.rs                 запуск FFmpeg с низким приоритетом и чтение прогресса
  updates.rs                проверка и установка обновлений
  shell.rs                  трей, горячие клавиши, окно
  capture/                  захват: источники, звук (WASAPI), FFmpeg, кольцевой буфер,
                            запись, определение игры
  editor/                   редактор: метаданные, превью, волна, нарезка, очередь,
                            дорожки, галерея, протокол для плеера
  config/                   настройки и определение кодировщиков видеокарты
scripts/release.ps1         выпуск новой версии
```
