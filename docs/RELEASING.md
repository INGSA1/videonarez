# Выпуск версий и обновления

## Как работает автообновление

Приложение при открытии окна и раз в 6 часов скачивает
`https://84-201-181-80.sslip.io/videonarez/latest.json`. Если там версия новее установленной,
сверху появляется полоса «Обновить и перезапустить». Установщик скачивается, его подпись
проверяется публичным ключом из `src-tauri/tauri.conf.json`, затем он ставится без вопросов,
и приложение перезапускается. Файл с неверной подписью установлен не будет.

Файлы обновлений раздаёт Caddy с сервера из папки `/var/www/videonarez-updates`
(путь `/videonarez/` сайта `84-201-181-80.sslip.io`, HTTPS выдаёт сам Caddy).

## Выпуск новой версии

```powershell
.\scripts\release.ps1 -Version 0.2.2 -NotesFile notes.md
```

Скрипт по порядку:

1. Проставляет версию в `tauri.conf.json`, `Cargo.toml` и `package.json`.
2. Собирает установщик и подписывает его ключом обновлений.
3. Загружает установщик и `latest.json` на сервер. `latest.json` загружается последним, чтобы
   приложения не увидели версию, файл которой ещё не докачан.
4. Проверяет по HTTPS, что сервер отдаёт новую версию.
5. Коммитит смену версии, отправляет её на GitHub и создаёт релиз `vX.Y.Z` на этом коммите
   с установщиком и подписью. Если релиз уже есть, обновляет его файлы.

Параметры:

| Параметр | Зачем |
|---|---|
| `-Notes "текст"` | короткое описание версии |
| `-NotesFile notes.md` | описание из файла (удобнее для длинного) |
| `-SkipBuild` | не пересобирать, загрузить уже собранное |
| `-NoGitHub` | только сервер, без релиза на GitHub |
| `-SshKey`, `-Server`, `-RemoteDir`, `-BaseUrl` | другой сервер или ключ |

## Ключи

- **Ключ подписи обновлений** — `%USERPROFILE%\.tauri\videonarez-updater.key`, без пароля.
  Храните резервную копию в надёжном месте. Без него следующее обновление подписать нельзя,
  а установленные копии принимают только эту подпись. Потеря ключа означает, что всем
  придётся один раз поставить новую версию вручную.
- **SSH-ключ сервера** — `%USERPROFILE%\.ssh\videonarez-server\`.

Ни один из ключей не хранится в репозитории.
